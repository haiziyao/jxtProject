# Markdown 文档界面

实验正文采用 [Vditor](https://github.com/Vanessa219/vditor) 4.0.0（MIT）替换原有 ByteMD 编辑器。编辑器与阅读页使用同一套 Markdown 渲染引擎，继续通过现有实验 API 保存 Markdown 字符串，没有数据库迁移。

## 使用

- 顶部切换“阅读 / 编辑”，切换时保留尚未保存的正文和记录信息。
- 默认使用即时渲染，也可通过工具栏切换所见即所得或 Markdown 源码模式。
- 工具栏支持标题、列表、任务、链接、图片、表格和代码块。图片继续通过现有上传与鉴权代理接口访问。
- 阅读页使用居中的文档版式，支持公式、代码高亮、脚注和标题目录；手机上目录折叠显示，源码编辑占满宽度。
- 点击“保存”或按 Ctrl / ⌘ + S 保存；上传图片时等待上传完成后保存。
- “导出 .md”导出当前正文，包括尚未保存的草稿。离开页面时会提醒尚未保存的内容。

原有正文、补充笔记和历史图片继续显示。加载与切换模式不会自动覆盖数据库中的正文；编辑器本身可能规范化用户编辑后的 Markdown 空白。

## 资源与构建

`npm run dev` 和 `npm run build` 先执行 `scripts/prepare-editor.cjs`，从锁定的 npm 包复制 Vditor 资源和许可证到 `public/vendor/vditor`。该目录为生成产物，不提交 Git。编辑器脚本、中文语言包、渲染引擎和样式由本站提供。

standalone 部署需要复制整个 `public` 和 `.next/static` 到 `.next/standalone`，与 README 中的部署方式一致。不要仅复制编辑器组件而遗漏资源目录。
