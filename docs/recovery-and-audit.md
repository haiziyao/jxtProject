# 恢复与检查记录

## 数据使用

现有数据库共 12 张表，包含 12 条实验、12 条笔记、2 个项目附件、1 个项目说明、5 位成员、1 位指导老师、1 条首页设置和 1 条待办；实验图片、标签、实验标签关联目前均为 0 条，另有迁移记录表。

- 实验及日期、记录人、简介：列表与详情展示。
- 实验笔记：带正文前缀的记录用于 Markdown 正文，其余笔记独立展示。
- 实验图片：详情页保留独立图片展示，当前表为空。
- 标签与实验标签关联：用于列表过滤和记录关联，当前表为空。
- 项目说明：展示首条及其他说明，首条支持编辑。
- 项目附件：预览及下载，使用已有对象存储文件。
- 首页设置：项目名称、展示姓名和进度。
- 团队成员与老师：登录后的首页“成员资料”展示独立成员表的班级、学号、电话和老师联系方式。展示姓名文本和成员档案分开保留；编辑首页文本不会改动档案。老师联系方式为空时显示“未填写”。
- 待办：使用数据库持久化，保留逻辑删除历史，并支持恢复。
- 迁移记录：供数据库工具维护，不作为业务内容展示。

Prisma 模型补齐已有成员、老师、首页设置及待办表的映射。本次无需数据库迁移。

## 修复范围

- 手机导航、表单、列表卡片、弹窗焦点、Markdown 编辑及预览布局。
- 实验元信息与正文在同一事务提交，重试复用正文笔记；保存失败保留输入。
- 首页及待办只更新请求中提供的字段，避免并发覆盖其他字段；创建待办直接返回插入结果。
- 严格验证日期、编号、重复或不存在的标签、JSON 格式、字段长度及中文 TEXT 字节容量。
- 删除实验图片必须匹配所属实验；不存在的删除请求返回 404。
- 对象存储代理检查源站和桶名，解码对象名；外部 Markdown 图片保留原始地址。
- 登录校验 JWT 签名、用途和有效期，禁止默认 JWT 密钥。

## 验证

自动化回归覆盖事务回滚、保存重试、日期、并发局部更新、中文字节限制、非法请求、对象地址和跨实验图片删除。部署前执行测试、Lint 与生产构建；上线后检查登录、数据读取、附件完整下载、页面资源及非法请求。

数据库核验使用各表完整行内容的排序 SHA-256 快照，核对部署前后行数与内容。生产核验只读取数据并发送应被拒绝的写入请求；正常写入与并发场景使用隔离的测试对象。私人备份与验证结果保留在运维目录，不入库。
